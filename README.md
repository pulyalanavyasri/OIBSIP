# Iris Flower Classification

## Objective
Train a machine learning classification model to identify the species of an iris flower (Setosa, Versicolor, or Virginica) based on physical measurements.

## Tech Stack
Python, scikit-learn, pandas, matplotlib, seaborn, Jupyter Notebook

## Approach
- Loaded the Iris dataset from scikit-learn
- Performed exploratory data analysis (EDA)
- Visualized feature relationships using pairplots
- Split data into training and test sets
- Trained two classifiers: Logistic Regression and Decision Tree
- Evaluated both models using accuracy, precision, recall, and F1-score

## Result
Both models achieved 100% accuracy on the test set. Logistic Regression was selected as the final model due to its simplicity.
